九、评测机制说明

本 benchmark 用于评估多 Agent 协作是否真的优于单 Agent，并把「多采样」与「协作」分开。每道题同时运行三种模式：

  • 单 Agent（基线）：一次 LLM 调用直接作答，无任何共识机制。
  • 单 Agent 自洽（公平基线）：同一 agent N 次独立采样 + 投票，剔除「多算几遍」带来的增益。
  • 多 Agent（LangGraph）：按题型映射到三种 LangGraph 拓扑——中心化（独立投票/中位数/代码流水线）、去中心化（圆桌/创意打磨/辩论）、分层（多视角并行+仲裁）。

正确性评分：数学题用规则评分（数值 1% 相对容差，客观精确）；其余 9 类用 LLM-as-Judge 对照参考答案/评估标准打「是/否」。

复用机制：结果按 (task_id, mode) 增量落盘，再次运行自动跳过已完成的答案与评分，无需整轮重跑。
